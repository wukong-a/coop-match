⚡ 自己部署一个节点，为网络出力

每多一个节点，网络就多一分匹配速度。自建节点会出现在全网「节点荣誉榜」上， 你促成的每一局跨节点配对都会被记录。一台低配云服务器、NAS、树莓派都能跑：

git clone 本项目 && cd it2-match
npm install
SIGNING=1 PORT=3001 NODE_NAME="你的节点名" HUB_URL= npm start

SIGNING=1 会让节点生成一对 Ed25519 密钥，跨节点配对时由双方各自签名存证—— 这样「荣誉榜上的数字」就不是枢纽单方面说了算，而是任何人都能复核的。存证里只有游戏名、时间和节点身份，不含任何玩家信息。
